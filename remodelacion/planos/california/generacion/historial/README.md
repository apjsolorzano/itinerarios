# Historial técnico

- `REVISIONES.md` resume los cambios acumulados.
- `estructura_anterior/` conserva la organización previa completa para trazabilidad.
- `validaciones_anteriores/` reúne comparaciones, renderizados de control, análisis de capas y SVG de prueba que antes estaban en `personal/tmp`.

El historial no debe utilizarse como fuente de los planos de obra actuales. Los PDF y paquetes comprimidos permanecen aquí únicamente como respaldo histórico.
