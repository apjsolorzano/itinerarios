# Itinerary HTML Style Guide

## Principal
- Siempre basate en el archivo instrucciones-ai/itinerario-plantilla.html

## Estructura
Cada itinerario debe incluir:
- Hero con destino, fechas y resumen.
- Resumen ejecutivo.
- Itinerario día por día.
- Restaurantes recomendados.
- Transporte.
- Presupuesto estimado.
- Consejos prácticos.
- Footer con fecha de actualización.

## Tono
- Español claro.
- Estilo premium, práctico y curado.
- No sonar genérico.
- Dar recomendaciones accionables.

## Diseño
- Mobile first.
- CSS embebido salvo que se indique lo contrario.
- No usar dependencias externas.
- No usar JavaScript innecesario.

## URLs
- Archivos en raíz.
- Slugs en minúscula sin tildes.
- Ejemplo: tokyo-2026.html.
